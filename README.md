**Migration and maintenance of the Coconutrate company website from a Laravel/cPanel-based setup to Cloudflare Workers.**

## Overview

Coconutrate is an existing company website originally developed and hosted on Laravel and cPanel.

This repository contains my work on migrating and adapting the website for Cloudflare while preserving its original design and content structure.

The migration focused on simplifying the hosting setup, replacing the previous backend dependencies, and keeping the website functional on a Cloudflare-based architecture.

## My Contributions

- Migrated from Laravel/cPanel hosting to Cloudflare Workers
- Configured deployment via Wrangler and connected the custom domain
- Rebuilt the contact form using a Cloudflare Worker with Email Routing
- Added a new Sensory Profile page and updated content
- Fixed the interactive 
- Improved responsive styling and layout

## Tech Stack

HTML · CSS · JS · Bootstrap · Cloudflare Email Routing · Cloudflare Workers · Wrangler
