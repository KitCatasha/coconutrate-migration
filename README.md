**Migration and maintenance of the Coconutrate company website from a Laravel/cPanel-based to Cloudflare Workers.**

## Overview

Coconutrate is an existing company website that was originally developed and hosted using Laravel and cPanel.

This repository contains my work on migrating and adapting the website for Cloudflare while preserving its original design and content structure.

The migration focused on simplifying the hosting setup, replacing the previous backend dependencies, and keeping the website functional on a Cloudflare-based architecture.

## My Contributions

- Migrated the website from Laravel/cPanel hosting to Cloudflare Workers
- Adapted the existing website into a static Cloudflare-compatible structure
- Configured deployment with Wrangler
- Connected the custom domain to Cloudflare
- Rebuilt the contact form using a Cloudflare Worker
- Integrated Cloudflare Email Routing for contact-form inquiries
- Added a new Sensory Profile page
- Updated website content
- Fixed the interactive Our Method section
- Improved responsive styling and page layout
- Maintained the original Coconutrate visual design throughout the migration
